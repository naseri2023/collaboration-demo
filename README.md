# Collaboration Demo Project

This project is used to practice Git and GitHub collaboration workflows.

## Project Purpose

This repository demonstrates a simple open-source development workflow using Git and GitHub.

It covers Issues, Branches, Pull Requests, Code Reviews, Merge, Rebase, Conflict Resolution, and Continuous Integration.

## How to contribute

1. Open an issue describing the proposed change.
2. Create a dedicated branch for the issue.
3. Make the required changes and commit them.
4. Push the branch to GitHub.
5. Open a Pull Request and link it to the related issue.
6. Address feedback from code review.
7. Wait for approval before merging.

## Continuous Integration

A GitHub Actions workflow automatically runs on every push and Pull Request to verify that the CI pipeline is working correctly.

This repository demonstrates a basic collaborative Git workflow.
